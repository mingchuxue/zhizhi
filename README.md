# 致知 · 物理实验台

面向高中生的交互式物理实验台，在浏览器里直接拖动、调参、观察。

在线访问：https://mingchuxue.github.io/zhizhi/

## 实验

- **抛体运动**：初速度、抛射角、抛出高度、重力加速度、空气阻力；理论值与实测值对照，速度分量随时间变化。
- **单摆**：小角度周期 2π√(L/g) 与大角度修正对比，可拖动摆球设定初始角度。
- **弹簧振子**：动能、弹性势能、机械能柱状图实时变化。
- **一维碰撞**：质量、速度、恢复系数可调，验证动量守恒并计算动能损失。
- **电场线与等势线**：拖动、添加、删除点电荷，电势背景与等势线。
- **磁场中的带电粒子**：洛伦兹力、轨道半径与周期，加上电场即为速度选择器。

纯静态页面，无需构建，直接打开 `index.html` 即可运行。
